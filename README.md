# Fringe-Event-187g-Combat-Robot
Fringe Event is a combat robot in the fairyweight weight class. It uses a compliant shuffling mechanism for locomotion. Its main weapon is a pair of forks that fold inwards, trapping its opponents. Fringe Event, evident in the name, is inspired by and themed on the tv show Fringe. Normal fairyweight robots are 150g, so you might wonder why this one is more. Since Fringe Event is a shuffler, it gets a 1.25x weight bonus.
